# 每周总结调度
目前没有安装定时任务。收集和删除始终手动触发。
在 Windows 任务计划程序中创建每周任务，具体时间由用户选择；北京时间周一 09:00 为建议值。
程序选择本项目 .venv/Scripts/python.exe，参数为 -X utf8 -m app.cli catch-up，起始目录为本项目。
启用“错过计划开始时间后尽快运行”，并设置“如果任务已在运行，不启动新实例”。
任务需要当前用户运行、能访问 D 盘与 DeepSeek API，机器关闭期间无法执行。
catch-up 只补充已结束自然周中有收集记录且缺少周报的周期，不检索、下载或删除论文。
可手动运行 start.cmd catch-up 验证，停用或删除该任务即可停止自动总结。
